## Overview

This repository contains the implementation of my Master's dissertation research in **Bayesian Deep Learning** and **Explainable AI**. The work investigates how counterfactual explanations can be generated by perturbing the **penultimate layer representations** of a deep classifier, guided by the uncertainty estimates of a **Bayesian last layer**.

The method avoids the use of external generative models and instead leverages the classifier’s own discriminative feature space. This results in counterfactuals that are more closely tied to the model’s actual decision boundary, while maintaining robustness through principled uncertainty quantification.

## Motivation

Most existing approaches to counterfactual explanation rely on **autoencoders, VAEs, GANs, or diffusion models** to enforce realism. These methods introduce several challenges:

* Their latent spaces are not organised according to the classifier’s decision boundary.
* They are computationally expensive, requiring repeated forward passes through large generative models.
* They can produce adversarial counterfactuals that do not correspond to meaningful explanations.

In contrast, the penultimate layer of a supervised classifier naturally encodes **decision-relevant features** and organises inputs such that instances of the same class are close together. This makes it a suitable space for counterfactual search.

## Method

We decompose a classifier of depth \$n\$ into:

* \$\phi(x)\$: the penultimate layer embedding produced by layers 1…n−1,
* \$p(y|\phi(x))\$: the prediction made by the final Bayesian layer.

To generate a counterfactual embedding \$\phi(x')\$, we optimise:

```math
\min_{\phi(x')} \mathcal{L}(\phi(x), \phi(x')) 
= -\log p(y_{\text{target}} \mid \phi(x'), D) 
+ \lambda \lVert \phi(x) - \phi(x') \rVert^2
```

Where:

* The first term encourages the counterfactual to be confidently classified as \$y\_{\text{target}}\$.
* The second term enforces proximity in the embedding space.

Since the Bayesian last layer learns a posterior distribution over its weights \$p(w\_L|D)\$, the target class prediction is defined as:

```math
p(y_{\text{target}} \mid \phi(x'), D) 
= \int p(y_{\text{target}} \mid \phi(x'), w_L) \, p(w_L|D) \, dw_L
```

Finally, to render counterfactuals in input space, a **decoder network** \$D: \phi(x) \to x\$ is trained to reconstruct inputs from their embeddings. The resulting explanation is given by \$x' = D(\phi(x'))\$.

## Architecture

The implementation consists of:

1. **Classifier (layers 1…n−1)**: deterministic feature extractor producing decodable embeddings.
2. **Bayesian Last Layer**: probabilistic linear classifier providing calibrated uncertainty.
3. **Counterfactual Optimiser**: gradient-based search over \$\phi(x)\$ guided by Bayesian uncertainty.
4. **Decoder**: reconstructs input space counterfactuals from embeddings.

## Advantages Over Generative Methods

* **Aligned space**: counterfactuals are generated in the classifier’s discriminative feature space.
* **Efficiency**: optimisation requires only repeated passes through the Bayesian last layer.
* **Robustness**: uncertainty estimates discourage adversarial or out-of-distribution perturbations.
* **Interpretability**: embeddings are closer to human notions of semantic similarity.

## Evaluation

The method was evaluated on image classification tasks with quantitative and qualitative comparisons against a baseline. Key findings include:

- **Bayesian vs. Deterministic**: Bayesian last-layer models produce clear, human-interpretable counterfactuals, while deterministic ones often fail or make tiny adversarial-like tweaks.
- **Stable Optimisation**: Bayesian uncertainty smooths decision boundaries, giving reliable gradients and near-zero optimisation failures.
